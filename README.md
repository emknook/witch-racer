# Witch Racer

A work-in-progress arcade broom-racing game concept using Godot and PSX-inspired Blender assets.

Try the [first handling prototype](game/README.md), or start with the [design documentation](docs/README.md), including the [game vision](docs/game-design/README.md), [eight playable racers](docs/game-design/characters.md), [story](docs/game-design/story.md), [technical architecture](docs/architecture/README.md), and [research backlog](docs/research/README.md).

**Status:** Early design. Proposed character names and story details are not yet approved. The first playable milestone is a focused racing vertical slice.
