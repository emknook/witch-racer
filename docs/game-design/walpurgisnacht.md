# Walpurgisnacht — recovered story setting

**Status:** Recovered from earlier user project discussions; narrative specifics should be reviewed before becoming canon.

Walpurgis is an ancient creature who has hunted witches for ages. She is imprisoned beneath the **Blackthorn Convergence Grounds**, but periodically escapes. Witches follow magically marked racing tracks, sometimes teleporting between far-flung locations, while the Wardens work to restore **thirteen seals** and recapture her.

## Previously discussed
- A decennial racing tradition and a **125th Walpurgisnacht race**.
- Madame Vesper Crowe, Professor Elspeth Bramblewick, Captain Iona Stormwake, Archwarden Corvus Vale.
- Earlier racer names: Aurelia Flint, Mara Mothwood, Tamsin Thistle, Yelena Morozova, Rook Belladonna, Zuri Nightfire, Maeve Copperkettle, Linh Phạm, Sorcha Graves, Pip Widdershins, Calista Starling, Agatha Crumb.

## Proposed game integration
Use **Walpurgisnacht: The Great Witch Escape** as the working narrative rather than the generic Grand Broom Prix festival. A short opening establishes the escape, the racing cups pass through magically linked locations, and a brief finale restores the seals. Keep a playful accessible tone and only **eight** selectable witches. Select which eight from earlier concepts with the project owner before changing the roster.
