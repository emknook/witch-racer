# Witch Racer — palette and materials board 03

**Focus:** a forest-route palette and material study, one coherent area for this update. This is a proposal to test against the confirmed PSX-inspired low-poly direction and Drummyfish environment-filler anchor. It does not establish a global palette or require copying any scene.

## Application notes

- Test a restrained warm ground against a cooler, darker forest silhouette.
- Keep track value and edge markings clearly separated from both ground and distant foliage.
- Treat emissive accents as gameplay signals (boost/hazard/checkpoint), not ambient decoration.
- Compare the same track section in a dark and a neutral lighting setup before adopting a palette.
- Any in-game material derived from these references should be simplified and authored as an original Witch Racer asset.
