# Decision log

## Confirmed by project owner
- Engine: Godot, with latest stable version as ongoing target.
- Modeling: Blender; visual direction: PSX-inspired low-poly.
- Modes: singleplayer and local multiplayer; future online multiplayer should remain architecturally feasible.
- Initial selectable roster: eight witches; blue, yellow, green, red, purple and mixed hair styles.
- Narrative: light, accessible story is desirable.
- Racing format: F-Zero-inspired, high-speed arcade racing on defined tracks; no unrestricted free flight. Banking, loops, and vertical elements are design directions to prototype.
- Repository is documentation source of truth; use structured Markdown and readable, prose-like code.

## Proposed, not yet approved
- Grand Broom Prix magical festival setting.
- Eight working names and personal motivations in [characters](../game-design/characters.md).
- Equal racer stats initially.
- First vertical slice with one track and two-player split-screen.

Record significant future choices here with rationale and consequences, rather than silently changing established requirements.
